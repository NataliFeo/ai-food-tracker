# AI Food Tracker — Природный баланс

Русскоязычный дневник питания: индивидуальная норма КБЖУ, распознавание еды по тексту/фото, проверка порций, рекомендации и история дней. Дизайн: тёплый светлый фон, лесной зелёный, шалфей и мягкие персиковые акценты.

## Запуск

Node.js 24 LTS. `npm ci`, скопировать `.env.example` в `.env.local`, заполнить серверный `OPENAI_API_KEY`, затем `npm run dev`. Для production: `npm run build`, `npm start`. `APP_ORIGIN` должен точно совпадать с адресом приложения. Секретные файлы исключены из Git.

## Стек и данные

Next.js App Router, TypeScript, React, Tailwind CSS, Zod, OpenAI Responses API. Без регистрации и базы данных. Анкета и дневник хранятся в localStorage браузера, поддерживается экспорт JSON. Фотографии сжимаются до 1024 px и не сохраняются в дневнике. Браузер отправляет еду на сервер только по действию пользователя. OpenAI получает текст/фото еды либо остаток КБЖУ; анкету и историю не отправляем. `store:false` отключает сохранение Responses; применяются правила обработки данных API OpenAI.

Расчёт по формуле Миффлина — Сан Жеора. Коэффициент активности 1.2–1.725, коррекция цели: снижение −15%, поддержание 0%, набор +10%, рекомпозиция −5%. Белки 1.6 г/кг (1.8 для набора/рекомпозиции), жиры 28% энергии, углеводы — остаток. Телосложение справочное. Приложение предназначено для взрослых; оценки не являются медицинскими рекомендациями.

## AI и расходы

По умолчанию `gpt-5.4-mini`, reasoning `none`, строгий JSON, максимум 1600 выходных токенов. Один запрос на анализ, один на рекомендацию по нажатию. Никакой истории чата или автоматических повторов. Итоги пересчитываются кодом. Модель задаётся через `OPENAI_MODEL`.

Лимиты: 20 AI-запросов/IP/сутки, 150/приложение/сутки, не чаще одного запроса за 4 секунды/IP. `AI_BUDGET_FILE` — постоянный файл счётчиков вне исходников; сохраняется после перезапуска. IP хешируются с датой, содержимое питания не записывается. Это ограничение числа запросов, не точный денежный бюджет OpenAI. Ручное добавление доступно при недоступном AI. Для нескольких процессов нужен общий атомарный лимитер; текущая конфигурация — один процесс Next.js за Nginx.

## Production

Сервис systemd от пользователя `foodtracker`, Nginx, HTTPS Let's Encrypt. Серверные секреты в `/etc/food-tracker.env` (root, 0600), состояние лимитов в `/var/lib/food-tracker`. Next.js слушает только 127.0.0.1:3000. Nginx перезаписывает `X-Real-IP`, задаёт предел тела 2 МБ и лимит частоты запросов. `/api/health` возвращает статус приложения без секретов. Конфигурация развёртывания в `deploy/`.

Проверки: TypeScript, production build, ручная проверка пользовательских сценариев. Автотесты и TDD не используются по спецификации.
